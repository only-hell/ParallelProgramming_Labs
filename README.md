# Лабораторная работа №4. Использование технологии NVIDIA CUDA

## 1. Постановка задачи
Перенос алгоритма перемножения квадратных матриц на графический процессор (GPU). Сравнение производительности с CPU-решениями и оценка эффективности архитектуры NVIDIA Ada Lovelace.

## 2. Аппаратная платформа
*   **GPU:** NVIDIA GeForce RTX 4050 Laptop (2560 CUDA ядер).
*   **Технология:** CUDA Toolkit 13.2.
*   **Особенности:** Использование 2D-сетки потоков и высокоточных событий CUDA для профилирования.

## 3. Результаты экспериментов
Для каждого размера матрицы проводилось 5 независимых запусков с автоматической верификацией через NumPy. В таблице приведены средние значения времени работы GPU-ядра.

| Размер (N) | Время на GPU (сек) | Время на CPU (сек)* | Ускорение (S) |
|:---|:---|:---|:---|
| **400**  | 0.0011 | 0.315 | ~286x |
| **800**  | 0.0064 | 2.437 | ~380x |
| **1200** | 0.0228 | 14.81 | ~649x |
| **1600** | 0.0516 | 43.68 | ~846x |
| **2000** | 0.0984 | 84.52 | **859x** |

*\* Данные CPU взяты из ЛР №1 и №3 на аналогичном объеме данных.*

## 5. Выводы
1. **Экстремальное ускорение:** Видеокарта RTX 4050 показала почти 900-кратное преимущество над центральным процессором на матрице 2000x2000. Это объясняется способностью GPU обрабатывать тысячи потоков одновременно.
2. **Масштабируемость:** С ростом размера задачи эффективность GPU только растет, так как накладные расходы на запуск ядра становятся незначительными по сравнению с объемом вычислений.
3. **Верификация:** Все тесты успешно прошли проверку на корректность, что подтверждает пригодность GPU для точных научных расчетов.
