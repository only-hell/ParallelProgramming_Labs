# Лабораторная работа №2. Многопоточное умножение матриц (OpenMP)

## 1. Цель и задачи
Адаптировать последовательную программу перемножения плотных квадратных матриц (из ЛР №1) для параллельных вычислительных систем с общей памятью. Оценить эффективность распараллеливания средствами стандарта OpenMP при варьировании размерности матриц и числа задействованных потоков (1, 2, 4, 8).

## 2. Среда тестирования и реализация
**Аппаратно-программный комплекс:**
* ОС: Windows
* Компилятор: MSVC (`cl.exe`) с включенной поддержкой `/openmp`
* Доступно логических потоков: 8

**Детали параллелизации:**
Для распределения вычислительной нагрузки применялась директива `#pragma omp parallel for`. Распараллеливанию подвергся внешний цикл итерации по строкам результирующей матрицы. Переменная-аккумулятор суммы объявлялась локально в области видимости каждого потока, что позволило избежать необходимости использования критических секций (`critical`) или атомарных операций (`atomic`), тем самым минимизировав накладные расходы на синхронизацию.

## 5. Аналитический вывод
Внедрение технологии OpenMP подтвердило свою состоятельность для задач матричного умножения. На основе собранной статистики сформулированы следующие выводы:
1. **Преобладание накладных расходов на малых объемах:** При $N \le 200$ использование 8 потоков не оправдано. Затраты ОС на порождение нитей и их синхронизацию съедают потенциальный выигрыш от распараллеливания (эффективность падает ниже 50%).
2. **Линейная масштабируемость:** Начиная с $N=400$, при переходе от 1 к 2 и 4 потокам наблюдается почти идеальное (линейное) масштабирование. Коэффициент эффективности держится в пределах 90–100%.
3. **Аппаратные лимиты:** Использование 8 потоков не дает 8-кратного ускорения (максимум $\approx 5.7x$). Это классическое поведение для архитектур, использующих логические ядра (Hyper-Threading). Математические вычисления с плавающей запятой непрерывно загружают физические FPU-блоки и упираются в пропускную способность кэш-памяти L3, из-за чего логические потоки простаивают в ожидании данных из RAM.
